## HAIKU-GENERATOR

This is my approach to solve the [Stack Overflow Challenge #25](https://stackoverflow.com/beta/challenges/80015893/challenge-25-count-your-syllables).

### Build

```bash
# Build the executable, 'haiku'
$ make

# Run tests
$ make test
```

### Usage

```bash
$ ./haiku Celebrate
Input: Celebrate (3)

Output:
Celebrate Always (5)
Incomprehensible A (7)
Communication (5)
```
